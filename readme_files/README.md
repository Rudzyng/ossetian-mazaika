Осетинская мозаика

Целью нашего проекта является создание пазлов на осетинском языке, развивающие мышление и проверяющие знания осетинских
слов.
Чтобы собрать мозаику, нужно менять картинки местами, нажимая на пару, совмещая части
мозаики с картинками и их названия на осетинском языке. 
Предназначено для детей и
взрослых, которые хотят проверить свои знания
осетинского языка.

Страницы:
1. Страница для регистрации: чтобы сохраниться в базе данных, нужно вставить свои данные в поля: почта, пароль, имя, фамилия.
2. Страница для входа в аккаунт: введи свои почту и пароль, которые ты указал при регистрации, и ты сможешь играть в разные уровни игры
3. Страница для выбора уровеня: на странице есть кнопки с номерами уровней. Нажми на любую из них, чтобы начать игру на выбранном уровне. Если хочешь создать свой уровень, нажми на кнопку "Создать уровень".
4. Страница уровня: все части пазла перемешаны. Чтобы собрать мозаику, выбери одну часть, передвинь ее на нужное место и отпусти. Часть пазла, стоявшая на месте отпускания, переместиться на место первой части
5. Страница для создания уровня: форма, в которую ты можешь вставить все необходимое: размер пазла, слова на осетинском языке, соответствующие им картинки, цвета, которые будут использованы в пазле и др.
