Осетинская мозаика

Целью нашего проекта является создание пазлов на осетинском языке, развивающие мышление и проверяющие знания осетинских
слов.
Чтобы собрать пазл, нужно менять картинки местами, нажимая на пару, совмещая части
пазла с картинками и их названия на осетинском языке. 
Предназначено для детей и
взрослых, которые хотят проверить свои знания
осетинского языка.

Страницы:
1. Страница для регистрации: Чтобы сохраниться в базе данных, нужно вставить свои данные в поля: почта, пароль, имя, фамилия.
2. Страница для выбора уровеня: на странице есть кнопки с номерами уровней. Нажми на любую из них, чтобы начать игру на выбранном уровне. Если хочешь создать свой уровень, нажми на кнопку "Создать уровень".
3. Страница уровня: все части пазла перемешаны. Чтобы собрать пазл, выбери одну часть, передвинь ее на нужное место и отпусти. Часть пазла, стоявшая на месте отпускания, переместиться на место первой части
4. Страница для создания уровня: форма, в которую ты можешь вставить все необходимое: размер пазла, слова на осетинском языке, соответствующие им картинки, цвета, которые будут использованы в пазле и др.
